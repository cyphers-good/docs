# 애니메이션 도식 생성 스킬

이 저장소의 애니메이션 도식은 "단계를 하나씩 진행하며 흐름을 이해시키는" 인터랙티브 컴포넌트입니다.
기준 구현은 `components/git-flow-diagram.tsx` 이며, 새 도식은 이 파일의 패턴을 재사용해서 만듭니다.
처음부터 새로 설계하지 말고, 반드시 기준 구현을 먼저 읽으십시오.

## 구성 요소 (기준 구현의 구조)

| 요소 | 역할 |
| --- | --- |
| `Appear` | 지정한 단계(`at`)에 도달하면 페이드인으로 나타나는 래퍼입니다. `delay`로 등장 순서를 조절합니다 |
| `DrawPath` | 지정한 단계에 도달하면 선이 그려지는 애니메이션입니다 (`stroke-dashoffset` 전환) |
| `Commit`, `LaneLabel`, `TagBadge` | 커밋 점, 레인 라벨, 태그 배지 프리미티브입니다 |
| `STEPS` 데이터 | 단계별 `title`, `desc` 목록입니다. 도식과 단계 패널이 이 데이터를 공유합니다 |
| 단계 패널 | 단계 목록을 한 줄씩 표시하고, 현재 단계를 강조하며, 클릭으로 이동합니다 |
| 컨트롤 | shadcn `Button`(`components/ui/button.tsx`) + lucide 아이콘으로 구성합니다. 처음부터/이전/다음/자동 재생 |

## 새 도식을 추가하는 절차

1. `components/<주제>-diagram.tsx` 파일을 만들고 `'use client'` 를 선언합니다.
   `git-flow-diagram.tsx` 의 `Appear`, `DrawPath` 등 프리미티브와 상태 관리(useState step, 자동 재생 interval) 구조를 그대로 가져와 장면(Scene)만 교체합니다.
2. 단계를 설계합니다. **한 단계는 하나의 의미 있는 변화**만 담습니다 (분기 하나, 머지 하나, 상태 변화 하나). 단계 수는 3~6개가 적당합니다.
3. SVG 장면을 그립니다 (아래 좌표·색상 규칙 참조). 각 요소에 `at={단계 번호}` 를 지정하고, 같은 단계 안에서 순차 등장이 필요하면 `delay` 를 0.2~0.3초 간격으로 늘립니다.
4. `mdx-components.tsx` 에 컴포넌트를 등록한 후, MDX에서 `<컴포넌트명 />` 으로 사용합니다.
5. 아래 검증 절차를 수행합니다.

## SVG 좌표·색상 규칙

- `viewBox` 는 가로 720~740 기준으로 잡고, 컨테이너에서 `width: 100%` 로 반응형이 되게 합니다.
- 주체(브랜치, 서비스)마다 가로 레인을 하나씩 배치하고, 레인 간격은 55px 내외로 유지합니다.
- 시간은 왼쪽에서 오른쪽으로 흐릅니다. 분기·머지 곡선은 `C` 베지어로 부드럽게 연결합니다.
- 색상은 주체별로 구분하며, 기존 팔레트를 재사용합니다: main `#e5484d`, dev `#0091ff`, feature `#30a46c`, release `#8e4ec6`, hotfix `#f76b15`, 태그 `#b98900`.
- 텍스트·배경은 라이트/다크 양쪽에서 보이도록 Fumadocs 변수(`var(--color-fd-foreground)` 등)를 사용합니다.
- 컨테이너·버튼·패널 스타일은 Tailwind 클래스와 shadcn 토큰(`bg-card`, `bg-accent`, `text-muted-foreground` 등)을 사용합니다. 하드코딩한 색을 UI 요소에 넣지 않습니다.

## 애니메이션 원칙

- 등장 전환은 0.45초, 선 그리기는 0.7초를 기준으로 합니다. 더 길면 답답하고, 더 짧으면 눈이 따라가지 못합니다.
- 자동 재생 간격은 1.5~2초로 설정하여, 읽는 사람이 단계 설명을 읽을 시간을 확보합니다.
- 단계 패널의 번호·설명은 도식의 진행과 반드시 일치해야 합니다. `STEPS` 데이터 하나를 도식과 패널이 공유하는 구조를 유지하십시오.

## 검증 절차

1. `npm run build` 가 통과하는지 확인합니다.
2. Playwright로 실제 렌더링을 확인합니다. 정적 빌드를 로컬 서버로 띄우고, "다음" 버튼을 끝까지 눌러 마지막 단계의 스크린샷을 찍어 확인합니다.

```bash
python3 -m http.server 3005 -d out &
# playwright 스크립트에서 executablePath: '/opt/pw-browsers/chromium' 사용
```

3. 중간 단계 하나를 클릭으로 이동해보고, 강조 표시와 도식 상태가 일치하는지 확인합니다.
